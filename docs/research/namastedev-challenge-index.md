## Suggested path for later original implementation

1. Start with easy React components and hooks, using independently written prompts, examples, solutions, and browser assertions.
2. Add JavaScript utilities and algorithms with explicit contracts and locally runnable tests.
3. Expand to intermediate UI state, async coordination, data tables, and hierarchical components.
4. Add harder exercises only after their runner requirements and edge cases are defined.
5. Before implementation, compare against the simulator's existing exercises to avoid duplicates. No duplicate audit has been performed for this reference index.

Approval would authorize creating our own exercises about selected concepts. It would not supply permission to reproduce NamasteDev's proprietary statements, solutions, assets, or fixtures.
