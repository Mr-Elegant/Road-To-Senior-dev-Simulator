# Reduce JavaScript and prefetch cost without weakening features

Collection: catalog · ID: `next-lab-frontend-delivery-budget` · Mode: **guided**

## Business context

The dashboard imports full answers, fixtures, editors and compilers for every challenge into its client bundle.

## Task

Design the system for 500 challenge routes; 200 KB compressed initial-route budget; low-end mobile devices. Produce the component/data-flow diagram, request and mutation contracts, cache/trust boundaries, capacity assumptions, failure recovery and rollout gates. State which decisions change between Next.js 15 and 16 instead of using a framework API as a substitute for an architectural guarantee.

## Candidate tasks

- Draw components and annotate ownership of data, identity, caches and durable work.
- Specify contracts/schema and quantify the capacity/freshness assumptions.
- Walk through the failure scenario and design measurable acceptance tests.
- Compare the reference decisions and answer the changed-requirement interview prompt.

## Constraints

- Ship summaries for listing/search.
- Load only selected challenge details.
- Preserve practice, search and account isolation.

## Follow-up questions

- Can a development timing prove a production performance win?
